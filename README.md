## About

A personal CV website built with HTML, CSS, and JavaScript. Open `index.html` in a browser to view it.

### Sections

- Personal Profile: name, title, photo, introduction, career objective
- Basic Information: location, email, contact number, career interests
- Education
- Technical and Professional Skills
- Projects
- GitHub Profile, with live stats from the GitHub API
- Contact and Social Links

### Features

- Responsive layout with a mobile menu
- Light and dark theme toggle
- Scroll animations, animated skill bars, typing effect, scroll progress bar

### Files

- `index.html`: page content
- `style.css`: styles and animations
- `script.js`: menu, theme toggle, animations, GitHub stats
